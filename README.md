# Student Management System

## Overview

The Student Management System is a web-based application developed using Python, Django, and MySQL. It helps educational institutions manage student records efficiently by providing features to create, view, update, and delete student information through an easy-to-use interface.

## Features

* Add new student records
* View all student details
* Update existing student information
* Delete student records
* User-friendly interface
* Database integration using Django ORM
* Responsive design using HTML and CSS
* Secure data handling and validation

## Installation

### Clone the Repository

```bash
git clone https://github.com/niki9209/Student-Management-System.git
cd Student-Management-System
```

### Create Virtual Environment

```bash
python -m venv myenv
```

### Activate Virtual Environment

Windows:

```bash
myenv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Apply Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

### Run the Server

```bash
python manage.py runserver
```

Open your browser and visit:

```text
http://127.0.0.1:8000/
```
